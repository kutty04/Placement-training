# Day 1 — Basics: Variables, Data Types, Input & Output

This folder contains beginner Python examples that introduce core language fundamentals: variables, basic data types, and simple input/output.

Files

- `datatypes.py` — Demonstrates common Python data types (int, float, str, list, tuple, dict, bool) and basic operations on them.
- `hello.py` — Minimal "Hello, World!" example.
- `input_output.py` — Shows how to read input from the user and print output.
- `input_type.py` — Example demonstrating reading input and converting between types.
- `input_types.py` — Additional input handling examples and type checks.
- `mydetails.py` — Interactive example that asks for user details (name, age, etc.) and prints a formatted response.
- `variables.py` — Illustrates variable assignment, reassignment, and simple operations.

How to run

From the repository root:

- python "Placement/Day 1/datatypes.py"
- python "Placement/Day 1/hello.py"

Or change into the folder and run directly:

cd "Placement/Day 1"
python datatypes.py

Notes

- These scripts are small learning examples; open them to inspect and modify inputs to experiment.
- If a script expects user input, run it from a terminal so you can type responses.
