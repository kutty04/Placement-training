# Day 2 — Conditionals, Comparisons & Operators

This folder focuses on conditional logic (if / else) and operator usage in Python. The examples demonstrate how to make decisions in code using comparisons and logical/arithmetic operators.

Files

- `Example program for if else` — A short example showing an if-else branch (may be a plain script without a `.py` extension; open to confirm the language).
- `Operators.py` — Demonstrates arithmetic, assignment, comparison, and logical operators.
- `comparison.py` — Examples using comparison operators (`==`, `!=`, `<`, `<=`, `>`, `>=`) and how they control flow.
- `if_else.py` — If / else examples illustrating branching based on conditions.
- `if_statement.py` — Another example focusing on single `if` statements and condition checks.

How to run

From the repository root:

- python "Placement/Day 2/if_else.py"
- python "Placement/Day 2/Operators.py"

Or change into the folder and run directly:

cd "Placement/Day 2"
python if_else.py

Notes & tips

- Try modifying the condition values to see how branches change.
- If a file does not have a `.py` extension, open it to confirm the language and add `.py` if needed.
- Add small tests or print statements to observe how expressions evaluate.
