# Day 5 — Loops and Range Practice

This folder contains example scripts and practice exercises focused on loops (for / while) and using the range() function. These were used during Day 5 of the placement training.

Files

- first_loop.py
  - A basic example demonstrating the first loop constructs (for/while) and iteration.
  - Run: python "Placement/Day 5/first_loop.py"

- n_to_one.py
  - Prints numbers from n down to 1 (demonstrates reversed ranges and loops).
  - Run: python "Placement/Day 5/n_to_one.py"

- one_to_n.py
  - Prints numbers from 1 to n (basic loop through a range).
  - Run: python "Placement/Day 5/one_to_n.py"

- print_odd.py
  - Prints odd numbers within a specified range.
  - Run: python "Placement/Day 5/print_odd.py"

- range_practice.py
  - Multiple small exercises showing range() usage with start/stop/step.
  - Run: python "Placement/Day 5/range_practice.py"

- sum_n.py
  - Calculates the sum of the first n natural numbers using a loop.
  - Run: python "Placement/Day 5/sum_n.py"

- table.py
  - Generates multiplication table(s) for a given number using loops.
  - Run: python "Placement/Day 5/table.py"

Notes

- These are small, self-contained Python scripts intended for practice and demonstration.
- Use Python 3.x to run these files.
