# Day 3 — Branching (elif), Number Checks & Comparison Examples

This folder contains small exercises showcasing multi-branch logic, simple numerical checks, and comparison problems.

Files

- `elif_statement.py` — Demonstrates using `if` / `elif` / `else` to handle multiple branches.
- `even_odd.py` — Example that checks whether a number is even or odd.
- `largest_of_three.py` — Given three numbers, determines the largest (comparison practice).
- `largest_of_two.py` — Basic example to compare two numbers and print the larger.
- `positive_negative_zero.py` — Checks if a number is positive, negative, or zero and prints the result.

How to run

From the repository root:

- python "Placement/Day 3/elif_statement.py"
- python "Placement/Day 3/largest_of_three.py"

Or change into the folder and run directly:

cd "Placement/Day 3"
python even_odd.py

Learning ideas

- Combine examples: build a small program that reads three numbers and prints whether each is even/odd and which is the largest.
- Add input validation to handle non-numeric entries gracefully.
- Extend `largest_of_three.py` to also print the second-largest value.
