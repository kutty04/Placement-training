# Day 4 — Conditionals

This folder contains examples and exercises for conditional statements (if / nested if) used during Day 4 of the placement training.

Files

- Three_condn_nested if.py
  - Demonstrates nested if statements and how to check multiple conditions in sequence.
  - Run: python "Placement/Day 4/Three_condn_nested if.py"

- divisible_y_5_and_11.py
  - Checks whether a given number is divisible by 5 and/or 11 and prints the result.
  - Run: python "Placement/Day 4/divisible_y_5_and_11.py"

- placement_eligibility.py
  - A sample script that evaluates placement eligibility based on given criteria (for example: grades, attendance).
  - Run: python "Placement/Day 4/placement_eligibility.py"

Notes

- These scripts are simple, self-contained Python files intended for learning and practice.
- Use Python 3.x to run these scripts.
